## F. Native / FFI safety

| Sev | Where | Problem | Suggested fix |
|---|---|---|---|
| MEDIUM | modules/renderer-gtk/src/main/scala/thicket/renderer/gtk/GtkRenderer.scala:784-791 (`formatDate`) | `g_date_time_new_utc` returns NULL outside years 1-9999. `CalendarDate` (Renderer.scala:553-560) validates the month and day but **not the year**. Then `g_date_time_format(NULL)` → a GLib critical plus NULL, and `fromCString(null)` → a segfault/NPE. `g_date_time_format` can also return NULL by itself (bad format or locale conversion), which isn't checked. | Null-check `dt` and `f` (fall back to ISO `y-m-d`), and add `require(year >= 1 && year <= 9999)` to `CalendarDate`. |
| LOW-MEDIUM | modules/renderer-apple/shim/Sources/Shim+AppKit.swift:1287-1316, Shim+UIKit.swift:1243-1271 | `return textScratch.withUnsafeBufferPointer { UnsafePointer($0.baseAddress!) }` lets the pointer escape the closure. Also, text of 4096 UTF-8 bytes or more returns `nil`, which Scala (`AppleInspect.scala:43-45`) can't tell apart from "not text-bearing". | Use a stable buffer: `private let textScratch = UnsafeMutablePointer<CChar>.allocate(capacity: N)` plus `strncpy`/`withCString`; grow it on demand, or return the length through an out-param so Scala can tell truncation from absence. |
