# Phase reviews

Whole-repository reviews, one dated folder each. A review is a snapshot: the findings
describe the tree at the commit named in its `REPORT.md`, and are not updated afterwards.
What was done about each finding is recorded in the PR that closed it.

| Date | Commit | Folder | Outcome |
|---|---|---|---|
| 2026-10-20 | `9c98d28` | [2026-10-20](2026-10-20/REPORT.md) | eight reviewers, 82 merged findings (P0 6 · P1 19 · P2 31 · P3 26) |

Each folder holds the consolidated `REPORT.md` and the per-reviewer reports it was merged
from; the report's IDs (`F-H1`, `A-MED-6`, …) point into those.
