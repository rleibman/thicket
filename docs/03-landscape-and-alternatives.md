# 3. Landscape and alternatives

Two questions: (a) what do other language ecosystems ship, so we know the bar and
can borrow designs; (b) which of those can Scala *reach* today through one of its
three backends, so we know the shortcuts available.

## 3.1 Cross-platform UI frameworks (other languages)

| Framework                     | Language              | Rendering strategy                                                                                           | Mobile                                | Desktop                                   | Native look                                             | Notes for us                                                                                                                                                   |
|-------------------------------|-----------------------|--------------------------------------------------------------------------------------------------------------|---------------------------------------|-------------------------------------------|---------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Flutter**                   | Dart                  | Custom (Impeller/Skia), Material + Cupertino widget sets                                                     | iOS, Android                          | Win, mac, Linux                           | Mimicked; good but not native; accessibility took years | Gold standard for DX (hot reload, `flutter` CLI). Proves AOT + custom renderer works; also proves how much it costs                                            |
| **React Native**              | JS/TS                 | Native widgets via shadow tree, Yoga layout, Fabric renderer (synchronous C++ core)                          | iOS, Android                          | Windows, macOS (Microsoft forks, lagging) | Native by construction                                  | Closest architectural analogue to what we propose. Its Yoga + "host components" split is directly borrowable. Its pain: JS runtime, upgrades, bridge history   |
| **Compose Multiplatform**     | Kotlin                | Custom (Skiko/Skia); iOS stable since 1.8 (May 2025); adaptive iOS behaviours; community `compose-cupertino` | iOS, Android                          | JVM desktop                               | Mimicked on iOS; Material default                       | The "what Kotlin got" reference. Requires a Kotlin compiler plugin; Scala cannot author composables, and Kotlin/Native cannot run Scala on iOS → no reuse path |
| **SwiftUI / Jetpack Compose** | Swift / Kotlin        | Platform-native                                                                                              | one each                              | one each                                  | Perfect                                                 | Define the fidelity bar and the declarative API idiom                                                                                                          |
| **.NET MAUI**                 | C#                    | Native widgets via handlers                                                                                  | iOS, Android                          | Win, mac                                  | Native                                                  | Same strategy as RN without JS; stability complaints common                                                                                                    |
| **Avalonia**                  | C#                    | Custom (Skia)                                                                                                | iOS, Android (newer)                  | Win, mac, Linux                           | Fluent theme, not native                                | Desktop-first Skia toolkit; shows single-renderer desktop is viable                                                                                            |
| **Uno Platform**              | C#                    | WinUI API mapped to native or Skia                                                                           | iOS, Android                          | Win, mac, Linux, Web                      | Mixed                                                   | Interesting "pick native or Skia per target" design                                                                                                            |
| **Qt / QML**                  | C++                   | Custom, platform styles                                                                                      | iOS, Android                          | Win, mac, Linux                           | Styled, close on desktop                                | Commercial licensing; C++ API                                                                                                                                  |
| **Tauri 2**                   | Rust + web            | System webview                                                                                               | iOS, Android (since 2.0, Oct 2024)    | Win, mac, Linux                           | Web                                                     | 2.11.x by mid-2026. Mobile "functional for internal tools". Scala.js frontend drops in trivially                                                               |
| **Capacitor / Ionic**         | Web                   | System webview + web components mimicking iOS/Material                                                       | iOS, Android                          | via Electron                              | Mimicked in CSS                                         | Scala.js + Laminar could target it today                                                                                                                       |
| **Electron**                  | Web                   | Chromium                                                                                                     | —                                     | Win, mac, Linux                           | Web                                                     | Memory-heavy; the thing Tauri exists to replace                                                                                                                |
| **NativeScript**              | JS/TS                 | Direct native API access from JS, native widgets                                                             | iOS, Android                          | —                                         | Native                                                  | Smaller community than RN                                                                                                                                      |
| **Lynx** (ByteDance, 2025)    | JS/TS                 | Native widgets, dual-thread                                                                                  | iOS, Android                          | Web                                       | Native                                                  | Young; another data point that "native widgets + declarative" keeps being reinvented                                                                           |
| **Slint**                     | Rust (+C++/JS/Python) | Custom                                                                                                       | Android (iOS experimental)            | Win, mac, Linux, embedded                 | Styled                                                  | Rust/C++ API; no C ABI for widget tree we could bind [unverified]                                                                                              |
| **JavaFX + Gluon Substrate**  | Java                  | Custom (Prism), Modena theme; Gluon Glisten for mobile                                                       | iOS, Android via GraalVM native-image | Win, mac, Linux                           | Not native                                              | The only path where **Scala runs on iOS today** via the JVM ecosystem (ScalaFX → GraalVM → Substrate). Niche, but real                                         |
| **libui-ng**                  | C                     | Native widgets (Win32, Cocoa, GTK)                                                                           | —                                     | Win, mac, Linux                           | Native                                                  | Tiny C API; desktop-only; bindable with sn-bindgen in a week                                                                                                   |

## 3.2 What exists in Scala today

| Project                                          | Backend        | Targets                                        | Status                                                           | Relevance                                                                                                                                                                                              |
|--------------------------------------------------|----------------|------------------------------------------------|------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Laminar / Airstream**                          | Scala.js       | Web                                            | Active, mature                                                   | Best-in-class reactive UI design in Scala; but Airstream is *deliberately* JS-only (author: no resources, would lose simplicity, JS single-threaded assumptions). Design inspiration, not a dependency |
| **scalajs-react**, **Slinky**                    | Scala.js       | Web; Slinky has `slinky-native` (React Native) | scalajs-react active; Slinky RN module at 0.7.x, little movement | Slinky-native is the *only* existing "Scala on a phone with native widgets" path; usable for a prototype; too stale to build on                                                                        |
| **Tyrian**                                       | Scala.js       | Web                                            | Active                                                           | Elm architecture in Scala 3 — a clean model for the optional MVU layer                                                                                                                                 |
| **Indigo**                                       | Scala.js, JVM  | Web, desktop (games)                           | Active                                                           | Proof Scala can do a real-time renderer; not a widget toolkit                                                                                                                                          |
| **ScalaFX**                                      | JVM            | Desktop (JavaFX)                               | Maintained                                                       | Combined with Gluon Substrate + GraalVM → iOS/Android. Non-native look                                                                                                                                 |
| **Scala Swing**                                  | JVM            | Desktop                                        | Maintenance                                                      | Dated; irrelevant except as history                                                                                                                                                                    |
| **scala-native-gtk-bindings** (indoorvivants)    | Scala Native   | Linux (GTK4)                                   | Published to Maven Central (`com.indoorvivants.gnome::gtk4`)     | Ready-made Linux renderer substrate                                                                                                                                                                    |
| **sn-bindgen** (indoorvivants)                   | Scala Native   | Any C library                                  | Active                                                           | Generates Scala 3 Native bindings from C headers via libclang — the tool for Yoga, libui, GTK, and for any C shim we write                                                                             |
| **sri** (chandu0101)                             | Scala.js       | RN                                             | Dead (2017)                                                      | History                                                                                                                                                                                                |
| **ScalaOnAndroid** guide (Kubuszok), scalac blog | JVM            | Android                                        | Blog-level, 2020–2023                                            | Evidence Scala 2.13/3 on Android via Gradle + R8 is possible with plumbing; not a maintained toolchain                                                                                                 |
| **scala-ios-demos** (Darkyenus)                  | JVM via RoboVM | iOS                                            | Dead (RoboVM is dead)                                            | History                                                                                                                                                                                                |

Conclusion: the *pieces* exist (bindgen, GTK bindings, Scala Native's C ABI export,
Scala.js), but nothing integrates them and nothing touches iOS or Android UIKit/Views
from Scala in a maintained way.

## 3.3 Shortcuts Scala could take today, and their ceilings

| Shortcut                                             | How                                                                                    | Ceiling                                                                                                                                                                                                                       |
|------------------------------------------------------|----------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Scala.js → React Native**                          | Refresh Slinky-native or write new facades over RN's host components; Expo for tooling | Native look on iOS/Android; desktop via Microsoft forks (lagging). You inherit RN's JS runtime, Metro bundler, upgrade churn and two toolchains (sbt + npm). Never becomes "Scala's framework"; always RN with a Scala accent |
| **Scala.js → Tauri 2 / Capacitor**                   | Laminar or Tyrian frontend in a webview shell                                          | Cheapest path to five platforms; web look; can't meet G1                                                                                                                                                                      |
| **ScalaFX → GraalVM native-image → Gluon Substrate** | Existing Java toolchain                                                                | Runs on iOS/Android; JavaFX look; small ecosystem; dependent on Gluon's GraalVM builds                                                                                                                                        |
| **Scala Native logic + Swift/Kotlin UI**             | `@exported` C ABI from Scala Native 0.5 for iOS/desktop; plain Scala/JVM on Android    | Not a UI framework — but it is the KMP-before-Compose model, and it is step one of the recommended architecture anyway                                                                                                        |
| **Scala Native + libui-ng**                          | sn-bindgen                                                                             | Desktop-only native widgets in weeks; no mobile                                                                                                                                                                               |

## 3.4 Architectural patterns worth borrowing

- **React Native's host-component split**: framework owns the tree, layout (Yoga) and
  diffing; platform owns leaf widgets. Fabric moved this to a synchronous C++ core —
  our Scala Native core is the equivalent without JS.
- **Compose's `remember`/state + recomposition scope** as the ergonomics bar; but
  implement with explicit signals (SolidJS/Preact-Signals style) to avoid needing a
  compiler plugin.
- **Flutter's tooling shape**: `create`, `run` with hot reload, `build`, `doctor`.
- **Compose Multiplatform's iOS-adaptive checklist** (native text selection, scroll
  physics, gestures, dynamic type) — with native widgets we get these free, but the
  list is our acceptance test.
- **Uno's "native or Skia per target"**: keep the renderer contract abstract enough
  that a Skia backend could be added later for embedded or for a
  consistent-look mode.
